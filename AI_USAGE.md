# AI tools and their use

This project was developed as part of the JetBrains Academy course *Build a Game with an AI Coding Agent*. AI-assisted development is a central part of that course and the game extension.

| Tool | Role in development |
| --- | --- |
| **JetBrains Junie** | AI-assisted coding while progressing through the game development course; assistance creating code and visual scene elements |
| **OpenAI ChatGPT** | Game design and feature planning, coding and debugging, extending triage/gameplay systems, tactical support simulation, start screen, English localization, documentation and test scripts |

The developer chose the game's direction, made design decisions, integrated the changes and performed local playtesting. AI-generated output was reviewed and modified iteratively.

No claim is made that game events, simulated patient metrics, or AI-assisted representations constitute clinical advice or a validated medical device.

Please correct or expand this list if any additional coding, visual, or audio AI tools were used in your final local copy.
